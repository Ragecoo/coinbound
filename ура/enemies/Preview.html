Coinbound · Противники

Четыре роли. Единый масштаб, фиксированная опора, отдельная анимация каждого направления.

Покой — фиксированная нейтральная поза. Атака в игре проигрывается один раз; здесь повторяется для проверки. Метка показывает опорную точку (32, 56). При прыжке перемещается игровой объект; спрайт остаётся относительно этой точки.

Формат и подключение
  • Основной атлас каждого врага: 512×512, 8×8 кадров по 64×64. Ряды: вниз движение/атака, влево движение/атака, вправо движение/атака, вверх движение/атака.
  • Отдельные файлы направлений: 512×192; ряды покой / движение / атака. Покой повторён восемь раз для одинаковой сетки.
  • Point / Nearest, без сжатия, без mipmaps; pivot (0.5, 0.125), 32 pixels per unit. Направления не отражать: свет нарисован отдельно.
  • Урон или выпуск снаряда — в начале кадра №4, при нумерации с нуля. Длительности кадров хранятся в behavior.json и EnemyBrain.cs.
  • Реакция на попадание и исчезновение после смерти выполняются движком; отдельных нарисованных циклов смерти в наборе нет.
  • Код — основа для подключения. Игровая сцена Coinbound этим пакетом не изменена. Полные правила интеграции находятся в README_RU.txt.
