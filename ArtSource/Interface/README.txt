Coinbound interface art

Current art was generated/adapted using the built-in image_gen tool.
The final prompts are in revision-prompts.json. Earlier crypt concept art is not used by the current UI.

Runtime assets in Assets/Coinbound/Resources/InterfaceArt:
menu-crypt.png: 320 x 180, drawn at 1280 x 720.
coinbound-logo.png: 160 x 120, drawn at 320 x 240; adapted from the user's Coinbound logo.
swordsman-portrait.png, archer-portrait.png: 72 x 96, drawn at 288 x 384.
Native-resolution integration is reproducible with Tools/Import-InterfaceArt.ps1;
unmodified generated sources are saved here as *-source.png.

outcast-sheet.jpg / seeker-sheet.jpg: portraits supplied by the user on 2026-10-30.
The illustrations were used as identity references for the new simplified pixel portraits.
The source sheets remain intact and are not displayed in the revised UI.
Point filtering, no mipmaps, no texture compression. No external paid UI pack is included.

UI frames, ornaments and particles are drawn by DungeonUiDecoration.
Fine diamond ability icons and gauges are drawn by DungeonHudGlyph.
Typography: Tiny5 from https://github.com/google/fonts/tree/main/ofl/tiny5
by the Tiny5 Project Authors, licensed under SIL OFL 1.1. The licence is included
beside the font in Resources/InterfaceFonts/OFL.txt. Cyrillic is supported.
